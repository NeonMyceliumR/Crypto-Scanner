# Crypto Volume Scanner

A tool to find unusual trading volume on small-cap coins using Binance data.

## What It Does

Scans the last 14 days of trading data on Binance and identifies coins with unusually high volume compared to their average. Great for spotting potential moves before they happen.

## Features

- Scans 2000+ trading pairs on Binance
- Calculates 14-day average volume
- Shows % change in volume
- Filters by minimum volume threshold
- Displays current price
